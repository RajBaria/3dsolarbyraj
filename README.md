# Helical Solar System (Android)

An interactive 3D simulation of our Solar System built with Kotlin and Jetpack Compose, migrated from the web-based 3D Solar System by Raj Baria (`RajBaria/3dsolarbyraj`).

## Key Features

- **Keplerian Orbital Mechanics**: 100% mathematically accurate orbital parameters based on NASA JPL J2000 epoch data for all planets, dwarf planets (Ceres, Pluto, Haumea, Makemake, Eris), and moons.
- **Helical Vortex Visualization**: Visualizes the Sun's sinusoidal orbit around Sagittarius A* in the galactic plane while the planets coil in 3D helical spirals through space.
- **Asteroid Belt & NEO Tracking**: Realistic particle simulation of the Asteroid Belt and tracking of Near-Earth Objects including asteroid 99942 Apophis and Halley's Comet with dynamic ion and dust tails.
- **Deep Space Environment**: Procedural 5-arm spiral galaxy with 3,500+ stars, Sagittarius A* supermassive black hole core, Oort Cloud, and nearby stellar systems (Proxima Centauri, Alpha Centauri, Barnard's Star, Sirius) with constellation line overlays.
- **Multilingual Support**: Fully localized in 6 languages: English, Gujarati (ગુજરાતી), Hindi (हिंदी), Spanish (Español), French (Français), and Japanese (日本語).
- **Time Controls**: Real-time simulation with variable time compression speeds (1 day/sec up to 100,000 years/sec), date display, today reset, and galactic angle 360° controls.
- **Interactive Camera**: Smooth touch gestures for orbit rotation, panning, pinch zoom, preset target tracking, and reset.
